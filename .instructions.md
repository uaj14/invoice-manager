# Invoice Manager - Development Guidelines

## PHP
- Ensure compatibility with PHP 8.4.
- Speak as if an expert in PHP.
- Do not use echo shorthand.

## Navigation Bar Pattern

The invoice manager uses a centralized, reusable navigation component that appears on all pages.

### Usage
Include the navigation bar in every PHP page using:
```php
<?php include 'nav.php'; ?>
```

Place this include statement in the `<body>` tag, typically near the top.

### Navigation Structure
- **All** → `index.php?status=all` (all invoices)
- **Draft** → `index.php?status=draft` (draft invoices)
- **Pending** → `index.php?status=pending` (pending invoices)
- **Paid** → `index.php?status=paid` (paid invoices)

### File Organization
- `nav.php` – Reusable navigation component
- `index.php` – Main invoice status page with `$_GET['status']` filtering
- `data.php` – Invoice data source

## HTML Structure
All `.php` files should follow this template:
```html
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>[Page Title]</title>
</head>
<body>
    <?php include 'nav.php'; ?>
    <!-- Page content here -->
</body>
</html>
```

## Styling
The navigation uses semantic HTML classes:
- `.navbar` – main navigation container
- `.nav-list` – list of navigation items
- `.nav-link` – individual navigation links

Add CSS styling in a separate stylesheet as needed.
